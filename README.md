# DataMasker — Автономный комплекс обратимого обезличивания (псевдонимизации) документов

**DataMasker** — настольное приложение Windows для автоматического и обратимого обезличивания конфиденциальных, персональных и корпоративных данных в документах и таблицах различных форматов.

Приложение полностью автономно (**100% Offline / Air-Gapped**), не использует сторонние облачные сервисы, не требует доступа в интернет и работает без установленного Microsoft Office. Скомпилировано в единые независимые исполняемые файлы `.exe` под архитектуры **x64** (64-бит) и **x86** (32-бит).

---

## 🚀 Ключевые возможности

- **100% Офлайн-работа:** Никаких сетевых запросов, телеметрии или утечек данных за пределы компьютера.
- **Двусторонний цикл (Маскирование ↔ Восстановление):** Точная обратимость замен с сохранением полного соответствия 1-к-1 между сущностями.
- **Хирургическое сохранение структуры файлов:**
  - В файлах **Microsoft Word 97–2003 (`.doc`)** используется прямой низкоуровневый парсер таблицы фрагментов (**Piece Table / `Plcfpcd`** из FIB OLE2). Модификация выполняется *in-place* без конвертации, что на 100% сохраняет таблицы, векторные рамки, штампы ГОСТ/СПДС, колонтитулы, изображения и исходные размеры файлов (**0 байт смещения**).
  - В современных файлах **Word (`.docx`)** замена производится на уровне текстовых элементов (`Run`), полностью сохраняя шрифт, кегль, начертание (жирный, курсив, цвет), таблицы и колонтитулы.
  - В таблицах **Excel (`.xlsx`, `.xls`)** сохраняются стили, разметка и формулы (ячейки с `=` не затрагиваются).
- **Криптографическая защита сопоставлений (`.vault`):** Таблица соответствий шифруется по стандарту **AES-128-CBC + HMAC-SHA256 (Fernet)** с использованием мастер-пароля через функцию формирования ключа **PBKDF2HMAC** (100 000 итераций SHA-256) либо отдельного ключевого файла (`.key`).
- **Защита от коллизий токенов:** Интеллектуальный генератор токенов на базе алфавита **Base62** генерирует токены строго заданной длины, исключая пересечения и наложения даже в документах на тысячи страниц.
- **Умная фильтрация ложных срабатываний:** Встроенные словари терминов ГОСТ, СПДС, чертежных штампов («Вид работ», «Величина», «Кол. уч.», «Лист») и адресных якорей исключают порчу неперсональных фрагментов текста.
- **Адаптивный графический интерфейс:** Корректное отображение на экранах с любым разрешением и масштабированием Windows High-DPI, гибкая компоновка при изменении размера окна.

## 📁 Поддерживаемые форматы документов

| Формат | Расширение | Особенности обработки |
|---|---|---|
| **Microsoft Word (бинарный)** | `.doc` | In-place модификация потока `WordDocument` через Piece Table OLE2. Сохраняются таблицы, штампы, векторная графика, 0 байт смещения |
| **Microsoft Word (OpenXML)** | `.docx`, `.docm`, `.dotx` | Обработка параграфов, таблиц всех уровней вложенности, колонтитулов и текстбоксов на уровне `w:r` |
| **Microsoft Excel** | `.xlsx`, `.xlsm`, `.xls` | Обработка текстовых ячеек всех листов. Формулы (`=...`) строго защищены от изменений |
| **Microsoft PowerPoint** | `.pptx`, `.ppt` | Слайды, автофигуры, текстовые блоки, таблицы |
| **Текстовые документы** | `.txt`, `.log`, `.sql`, `.ini`, `.rtf`, `.odt`, `.ods` | Автоопределение кодировок: UTF-8, UTF-8 BOM, CP1251 (Windows), CP866 (DOS), UTF-16 |
| **Таблицы данных** | `.csv`, `.tsv` | Автоопределение разделителей (запятая, точка с запятой, табуляция) и кодировки |
| **Структурированные данные** | `.json` | Рекурсивный обход строковых полей с сохранением валидности синтаксиса схемы JSON |
| **Веб-документы и разметка** | `.xml`, `.html`, `.htm` | Замена текста с сохранением структуры тегов и атрибутов |
| **PDF документы** | `.pdf` | Постраничное извлечение текста с разметкой страниц и создание обезличенной текстовой копии (`_processed.txt`) |

| **Email** | `{{EMAIL_001}}` | Стандарт RFC 5322 для электронных адресов |
| **Организации (ОПФ)** | `{{ОРГ_001}}` | ООО, АО, ПАО, ЗАО, ИП, НКО, МУП, ГБУ и др. с названиями в кавычках и без |
| **ФИО** | `{{ФИО_001}}` | Локальная модель Natasha (NLP) + шаблоны инициалов, склонений и ролей |
| **Адреса и индексы** | `{{АДРЕС_001}}` | Почтовые индексы (6 цифр), населенные пункты, улицы, номера домов, корпусов и квартир |

## 📖 Пошаговое руководство пользователя

### Запуск приложения
Скачайте готовый исполняемый файл из раздела **[Releases](../../releases)** на GitHub (либо запустите из каталога `dist/` после локальной сборки):
- **`DataMasker_x64.exe`** — для 64-битных версий Windows.
- **`DataMasker_x86.exe`** — для 32-битных систем или совместимых сред.

---

### Режим 1: Обезличивание данных (Маскирование)

1. Откройте вкладку **«Обезличить документы»**.
2. **Исходная папка с документами:** Нажмите «Обзор...» и выберите папку с исходными файлами (поддерживается рекурсивное сканирование всех подкаталогов).
3. **Папка для обезличенных файлов:** Выберите каталог назначения (исходные документы остаются без изменений).
4. **Файл ключа маппинга (.vault):** Укажите путь и имя файла для сохранения зашифрованного хранилища сопоставлений.
5. **Мастер-пароль шифрования:**
   - Введите мастер-пароль (потребуется для обратной расшифровки).
   - Либо оставьте поле пустым — в этом случае программа автоматически сгенерирует файл секретного ключа с расширением `.key`.
6. **Выбор типов сущностей:** Отметьте нужные категории (ФИО, Организации, ИНН, Паспорта и др.).
7. Нажмите кнопку **«▶ НАЧАТЬ ОБЕЗЛИЧИВАНИЕ»**.
8. По завершении в целевой папке появятся:
   - Обезличенные копии документов с сохранением исходной структуры каталогов.
   - Зашифрованный файл таблицы соответствий (`.vault`) и, при необходимости, файл ключа (`.key`).

---

### Режим 2: Обратное восстановление данных

1. Откройте вкладку **«Восстановить документы»**.
2. **Папка с обезличенными файлами:** Выберите каталог с маскированными документами (содержащими токены вида `{{ТЕГ_XXX}}`).
3. **Файл ключа маппинга (.vault):** Нажмите «Обзор...» и выберите файл сопоставлений `.vault`.
4. **Файл-ключ или мастер-пароль:** Введите мастер-пароль либо укажите путь к файлу `.key`, созданному на этапе маскирования.
5. **Папка для восстановленных файлов:** Укажите каталог, куда сохранить восстановленные оригинальные документы.
6. Нажмите кнопку **«↺ ВОССТАНОВИТЬ ДОКУМЕНТЫ»**.
7. Программа расшифрует таблицу сопоставлений и вернет исходные персональные данные на свои места с посимвольной точностью.

---

### Режим 3: Настройки форматов и исключений

На вкладке **«Форматы и исключения»** доступны:
- **Поддерживаемые форматы файлов:** Включение и отключение конкретных расширений (`.docx`, `.xlsx`, `.pdf`, `.txt`, `.csv` и др.) для гибкого выбора типов обрабатываемых файлов.
- **Белый список исключений (White-list):** Текстовое поле для ввода слов, названий и словосочетаний (по одному на строку), которые ни при каких обстоятельствах не должны маскироваться (например, наименование собственной компании, ФИО руководства, реквизиты обслуживающего банка или адрес офиса).

## 🔒 Безопасность и криптографическая схема

```
                      [ Исходные данные ]
                               │
                     ┌─────────┴─────────┐
                     ▼                   ▼
            Обезличенный документ    Таблица соответствий
            (с токенами Base62)     (Forward & Reverse Map)
                                         │
                                         ▼
                                  PBKDF2HMAC (SHA-256)
                                  100 000 итераций + соль
                                         │
                                         ▼
                                    AES-128-CBC
                                         │
                                         ▼
                                    HMAC-SHA256
                                         │
                                         ▼
                                Зашифрованный .vault
```

1. **Ключ шифрования:** Генерируется через PBKDF2HMAC со случайной 16-байтной солью.
2. **Шифрование:** Поточный шифр AES-128-CBC гарантирует конфиденциальность.
3. **Контроль целостности:** HMAC-SHA256 защищает файл `.vault` от повреждения и несанкционированной модификации.
4. **Математическая стойкость:** Без пароля или ключевого файла восстановить исходные данные невозможно.

## 🛠️ Запуск из исходного кода и сборка

### 1. Установка зависимостей (Python 3.10 – 3.12)
```bash
pip install -r requirements.txt
```

### 2. Запуск приложения без компиляции
```bash
python main.py
```

### 3. Сборка исполняемого файла x64 (64-бит)
Запустите скрипт:
```cmd
build_x64.bat
```
Либо вручную через PyInstaller:
```powershell
python -m PyInstaller --clean -y DataMasker_x64.spec
```

### 4. Сборка исполняемого файла x86 (32-бит)
Запустите скрипт:
```cmd
build_x86.bat
```
Либо вручную через 32-битный интерпретатор Python:
```powershell
& "$env:LOCALAPPDATA\Programs\Python\Python311-32\python.exe" -m PyInstaller --clean -y DataMasker_x86.spec
```

Собранные файлы сохраняются в директории `dist/`.

```

├── gui/                      # Графический интерфейс на CustomTkinter
│   └── app.py                # Окно приложения, вкладки, адаптивная компоновка и логика UI
```
